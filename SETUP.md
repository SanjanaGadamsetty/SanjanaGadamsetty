# Setup · Neon Terminal GitHub Profile

1. Create a **public** GitHub repository named exactly `SanjanaGadamsetty` under the `SanjanaGadamsetty` account. GitHub treats a matching public repo's root README as the profile README.
2. Copy the **contents** of this folder to the root of that repository, preserving `.github/workflows/` and `assets/generated/`.
3. In repository **Settings → Actions → General → Workflow permissions**, enable **Read and write permissions** if your repository permits it. Both workflows require contents: write. Some organizations may restrict this setting.
4. Go to **Actions → Refresh terminal dashboard → Run workflow**. The workflow refreshes generated SVGs and commits them to the default branch. Scheduled runs then refresh daily.
5. Go to **Actions → Generate contribution snake → Run workflow**. It publishes `snake.svg` to an `output` branch. It may take a short while for the raw GitHub URL to become available.
6. Review and adjust project descriptions, coding-profile URLs, and LinkedIn URL. They are provided as editable starting points, not automatically verified.
7. If your GitHub username changes, replace `SanjanaGadamsetty` in README links. The generator uses the repository owner automatically.

## Data and limitations
- `stats.svg`: public repo count and follower count from GitHub's REST API; star total covers the first 100 non-fork public repos (the script intentionally excludes forks). The number of recent public events is limited by GitHub's public events API.
- `activity.svg`: 12 weeks of public events only. It is **not** an official GitHub contribution calendar and excludes private activity and older public events outside the API window.
- `languages.svg`: counts the primary language of each of the first 100 non-fork public repos, not code-byte percentages or a verified skill level.
- `projects.svg`: five most recently updated non-fork public repos.
- `opensource.svg`: recent public pull requests found via GitHub issue search; search results may be incomplete or delayed.
- `snake.svg`: generated by a third-party action and hosted in the `output` branch; it reflects the GitHub contribution graph that action can access.
- GitHub README markdown does not run custom JS/CSS, and GitHub may render tables differently on mobile.
- GitHub Actions cron can run late or occasionally be skipped; workflows may be disabled after long repository inactivity. Manual dispatch is available.
- The typing animation uses a third-party hosted SVG service. If unavailable, its image will not render.
- Public API calls can be rate limited. Generator degrades gracefully, but panels may be incomplete if GitHub API calls fail.

## Security
The workflow uses the repository-provided `GITHUB_TOKEN` only; no personal access token is needed. Tokens are not written to generated files. External Actions are pinned to major versions here for ease of maintenance; for stricter supply-chain security, pin them to reviewed commit SHAs.
